# Changelog

All notable changes to this project are documented here.

## Unreleased

- Public-repository documentation and contribution guidance.
- Ubuntu CI coverage for `x86_64` and `aarch64`.

## 0.2.0

- Resumable local transcription for Persian and English audio and video.
- Guided menu, composer, command-line, and script-friendly one-shot workflows.
- Canonical raw transcripts preserved separately from formatted exports.
- Optional word alignment, speaker diarization, transcript comparison, and analysis.
- WhisperX and whisper.cpp recognition backends.
