# Support

For usage questions and reproducible bugs, open a GitHub issue in this repository.
Include:

- the command you ran, with tokens and private paths removed;
- operating system and CPU architecture;
- Python version and selected engine;
- output from `./cli status`, after removing personal paths;
- the smallest useful error excerpt and reproduction steps.

Do not attach private recordings, transcripts, model caches, or `.env` files. Use a short
synthetic recording or describe the media properties instead.

For questions about an upstream dependency or model, check its own issue tracker and model
card as well. The relevant links and licenses are listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
